# Chytalka — офлайн читалка з озвучкою (Android)

Kotlin + Compose, FB2/EPUB/TXT, укр/рос/англ, фонове відтворення, збереження позиції, таймер сну, швидкість.

## Збірка (Windows)
1. `powershell -ExecutionPolicy Bypass -File setup.ps1` — качає sherpa-onnx AAR (v1.13.8) і Piper-моделі uk/en/ru в assets (~200 МБ).
2. Android Studio → Open → ця папка → Sync → Run на телефоні (arm64, Android 8+).

## Двигуни
- **Системний** — Google/інший TTS, лише офлайн-голоси (встанови голос укр/англ/рос у налаштуваннях Android).
- **Piper** — sherpa-onnx, повністю в застосунку. Наступне речення синтезується наперед.

## Підготовка книги (економія батареї)
Один раз на книгу: поділ на речення, мова кожного речення, словник вимови. Кеш у `files/prep_*.tsv`.
Словник: `Android/data/ua.vatsuo.chytalka/files/pronunciation.txt`, рядки `слово=як звучить` (напр. `Гаррі=Гері`). Після зміни книга переобробиться автоматично.

## Налаштування
- Рядків тексту: `VISIBLE_LINES` у MainActivity.kt
- Голос Piper для uk має 3 спікери: `generate(..., sid = 0)` у TtsEngine.kt

## v2 — що виправлено
- **Артефакти Piper**: нормалізація тексту (лапки, тире, дужки, «…», цифри→слова укр.), речення ≤200 символів, дуже короткі зливаються з наступним, кожне закінчується розділовим знаком.
- Нижчий шум моделі (`NOISE`, `NOISE_W` у TtsEngine.kt), перевірка кожного кліпу (тривалість/кліпінг) з до 3 спроб, fade 8 мс проти клацань, коротка пауза між реченнями, випереджальний синтез на 2 речення.
- Вибір голосу Piper (1–3) — подивись, який дає менше глюків.
- Сервіс: сповіщення більше не «воскресає» після Stop, foreground лише під час відтворення, коректна реєстрація receiver на Android 14.
- Числа читаються у називному відмінку (без узгодження), наголоси автоматично не ставляться.
